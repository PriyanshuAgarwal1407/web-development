Inline, Block & Inline-Block Elements

1. Block Elements

Block elements always start on a new line and take the full available width by default.

I am a div (Block Element)
I also start on a new line.

2. Inline Elements

Inline elements stay on the same line and only occupy the space required by their content.

Width and height are ignored on normal inline elements.

Inline-block elements stay on the same line like inline elements, but width and height also work.
