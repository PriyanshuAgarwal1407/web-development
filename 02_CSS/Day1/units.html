Units in CSS

In CSS, units are used to define the size and dimensions of elements. There are various types of units available, including absolute units, relative units, and percentage-based units.

Solution 1: Absolute Units

Solution 2: Relative Units

This div has a width of 20 rem and a height of 10 rem.

Solution 3: Viewport Units

This div has a width of 50% of the viewport width and a height of 50% of the viewport height.

This div has a width of 100% of the viewport width and a height of 100% of the viewport height.

This div has a width of 10 vmin and a height of 10 vmax.
